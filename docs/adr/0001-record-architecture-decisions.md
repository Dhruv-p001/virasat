# 0001. Record architecture decisions

Status: Accepted · 2026-11-03

## Context

The brief (section 9) asks for an ADR for every significant decision or deviation from the brief.

## Decision

Each decision gets a numbered file in `docs/adr/`, with the following sections: Status, Context, Decision, Consequences. Status is one of Proposed, Accepted, Superseded by NNNN. When a decision is replaced, the old ADR stays in the folder and gets the status "Superseded by NNNN".

## Consequences

Future sessions (human or Claude) can see why something is the way it is before changing it.
